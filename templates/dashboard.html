Effective Data Management

Upload Best Practices

  • • Use CSV or Excel files with headers in first row
  • • Ensure consistent date formats (YYYY-MM-DD)
  • • Remove empty rows and columns
  • • Keep file size under 50MB for optimal performance

Dataset Switching

  • • Use dropdown to switch between datasets
  • • Filters reset automatically when switching
  • • Charts update in real-time
  • • Custom datasets can be deleted if needed

Smart Filtering Strategies

📅 Date Filtering

Use start and end dates to focus on specific time periods. Leave blank for all-time analysis.

🏷️ Category Filters

Select multiple values from dropdown lists. Hold Ctrl/Cmd to select multiple items.

🔍 Search Function

Use the search box to find specific records across all columns instantly.

Pro Filtering Tip

Combine date and category filters for precise analysis. Start broad, then narrow down progressively for best insights.
